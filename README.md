# Basic Encryption & Decryption

A Python-based implementation of basic encryption and decryption using the Caesar cipher.

## Project Description

This project demonstrates the basic concepts of encryption and decryption by applying a Caesar cipher to user-provided text.

The program allows the user to:

- Enter text to encrypt
- Choose a shift key
- Encrypt the text
- Decrypt the encrypted text
- Display the original, encrypted, and decrypted text

## How the Caesar Cipher Works

The Caesar cipher encrypts text by shifting each letter by a fixed number of positions in the alphabet.
